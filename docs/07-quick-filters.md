# Quick filters

Right-click a supported event cell and choose **Quick Filter** with either equals or not-equals. The action uses the cell's underlying field/value to include or exclude matches. The context menu and quick-filter badges also provide ways to clear these restrictions.

Quick filters combine with Advanced Filter, profiles and other active restrictions. Repeated values within a field and exclusions need to be read together; an added restriction can legitimately produce no rows. Check the active tab rather than assuming every tab has the same column-filter state.

**Clear Quick Filters** removes quick-filter restrictions; it does not remove every other filter layer or a pivot tab's base scope. **Clear All Filters** is the broader reset action for ordinary filter layers.

For multiple checkbox selections use [column filters](08-column-filters.md). For an event-centered expansion use [Around this event](09c-around-this-event.md). There is no fixed set of incident-detection preset chips in this workflow.
